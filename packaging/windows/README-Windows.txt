AI Native Engine - Windows 打开方式

1. 解压整个文件夹，不要只复制单个 HTML。
2. 双击 Start AI Native Engine.bat。
3. 浏览器会自动打开本地地址，例如：
   http://127.0.0.1:5173/
4. 使用时保持黑色命令窗口打开。
5. 不用时关闭命令窗口，或者按 Ctrl+C 停止。

注意：

- 不需要安装 Node.js。
- 不建议双击 app/index.html，因为 3D 模型、贴图和模块资源在 file:// 下容易被浏览器拦截。
- 如果 5173 被占用，启动器会自动尝试 5174、5175 等端口。
- 如果 Windows 安全提示网络访问，允许本机/专用网络即可。
- 如果浏览器没有自动打开，可以复制命令窗口里显示的 http://127.0.0.1:端口/ 到 Chrome 或 Edge。
